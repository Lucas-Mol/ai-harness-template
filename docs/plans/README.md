# Plans

Execution plans for non-trivial work. Copy [TEMPLATE.md](TEMPLATE.md) to `active/NNNN-short-title.md`.

- `active/` — approved or in-progress plans. Each must contain a checklist (`harness-lint` enforces it).
  `harness-gc` reports plans not updated within `plans.stale_after_days`.
- `completed/` — finished plans with a final handoff, kept as history.
