# ADR-0003: Track generated adapter files with a manifest

- **Status:** Accepted
- **Date:** 2026-10-14
- **Deciders:** template maintainers

## Context

Generated files must be recognisable (to block hand edits and to find orphans when a target is removed).
Markdown and TOML can carry a `GENERATED BY scripts/harness/sync — DO NOT EDIT` comment, but JSON
(`.claude/settings.json`, `.mcp.json`, `.gemini/settings.json`) cannot, and some tools validate unknown keys.

## Decision

`sync.py` writes `.agents/.generated.json`: a manifest of every generated path and its SHA-256.
Files that support comments also carry the header (after the YAML frontmatter, which must come first).
Paths that were generated before but are no longer produced are **orphans**: they are listed, kept in
the manifest and only deleted with `make harness-sync ARGS=--prune` after confirmation.

## Consequences

- **Positive:** JSON adapters are tracked; removing a target never deletes files silently.
- **Negative:** one more generated file to commit.
